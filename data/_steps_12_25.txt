Σs=PsPs'⟹A0-1s=Ps[cite: 1]

X=QR

A0-1=PsQ

Step 16: Convergence Diagnostics, Autocorrelation Analysis, and Efficiency Benchmarks
Step 16 provides the formal MCMC convergence assessment, mixing diagnostics, and numerical precision metrics for all estimated parameters, latent dynamic states, and time-varying network quantities across the retained Gibbs sampling chain.
1. Potential Scale Reduction Factor (Gelman-Rubin Diagnostic R)
Run M≥3 independent parallel Markov chains starting from overdispersed initial values for S post-burn-in iterations. For any scalar target θ (e.g., hypervariances τ2, loading entries Fij, covariance elements Σij, or states λi,t,Bk,tij):
Between-Chain Variance (B):
B=SM-1m=1Mθm∙-θ∙∙2
where θm∙=1Ss=1Sθms is the mean of chain m, and θ∙∙=1Mm=1Mθm∙ is the grand mean.
Within-Chain Variance (W):
W=1MS-1m=1Ms=1Sθms-θm∙2
Marginal Posterior Variance Estimate (Varθ):
Varθ=S-1SW+1SB
Scale Reduction Factor (R):
R=VarθW
Values of R≤1.05 across all sampled dimensions indicate adequate convergence and inter-chain stationarity.
2. Effective Sample Size (ESS) and Inefficiency Factors (IF)
Because dynamic state transitions (FFBS) and variance parameters often exhibit serial dependence across MCMC iterations, mixing performance is evaluated using autocorrelation times:
Autocovariance at Lag k:
γk=1Ss=1S-kθs-θθs+k-θ
ρk=γkγ0
Inefficiency Factor (IF or Integrated Autocorrelation Time τint):
Using a Parzen or Tukey-Hanning taper window with bandwidth cutoff Kcut:
IFθ=1+2k=1Kcutwkρk
Low values (IF<20) indicate rapid mixing; higher values reveal persistent autocorrelation typical in dynamic latent trajectory sampling.
Effective Sample Size (ESS):
ESSθ=SIFθ=S1+2k=1Kcutwkρk
A target of ESS≥400 per parameter is typically enforced for reliable 95% credible interval coverage.
3. Numerical Standard Errors (NSE) via Batch Means
Quantify the Monte Carlo sampling variation around the estimated posterior expectations θ=Eθ∣Y:
Partition the S samples into Bbatch contiguous, non-overlapping batches of length Lbatch=S/Bbatch (with Lbatch sufficiently large so batch means are approximately uncorrelated):
θb=1Lbatchs=b-1Lbatch+1bLbatchθs, b=1,…,Bbatch
Compute the Numerical Standard Error:
NSEθ=1BbatchBbatch-1b=1Bbatchθb-θ2
The ratio NSEθ/stdθ verifies whether simulation noise is negligible relative to posterior posterior parameter uncertainty.
4. Geweke Spectral Diagnostic for Chain Stationarity
Assess within-chain drift by testing whether the mean of the early fraction of the chain matches the mean of the late fraction:
Let θA denote the mean over the first SA=0.10S iterations, and θB denote the mean over the last SB=0.50S iterations.
Compute spectral density estimates at zero frequency for each segment, SA0 and SB0:
ZGeweke=θA-θBSA0SA+SB0SB
Under the null hypothesis that the chain reached its stationary target distribution after burn-in, ZGeweke→dN0,1. Rejection rates across parameter dimensions should align with the nominal false-positive rate α=0.05.
5. Diagnostics Pipeline Protocol
Chain Run: Run M=3 chains for Ntotal=20,000 iterations each, discarding the initial Nburn=5,000 iterations as burn-in.
Global Trace Inspection: Generate trace plots for hypervariances τλ2,τλ2,τF2,τU2,τV2,τu2,τv2 and sample diagonals of Σ to check for path stability and label sticking.
Automated Flagging: Compute R, ESS, and Geweke Z-scores across all T points of the dynamic paths μt,Bk,t,Wt.
Thinning Decision: If memory constraints exist or IF exceeds threshold bounds, apply systematic thinning (e.g., retain every 5th or 10th draw) to store uncorrelated samples for subsequent structural and policy analyses.
Step 17: Implementation Architecture, Computational Optimization, and Software Pipeline
Step 17 establishes the computational pipeline, low-level linear algebra accelerations, memory management schemes, and parallelization structures required to execute the complete Gibbs sampler across high-dimensional time series (n≫1) and long sampling horizons (T).
1. Dimensionality Profiling and Computational Bottlenecks
At each MCMC iteration, the sampler processes three primary high-dimensional computational blocks:
Network Latent Probit Updates (Steps 1–3): On2T truncated normal draws and 2n independent Kalman filter/FFBS updates of dimension r.
Dynamic Intercept Factor Paths (Step 4): Kalman filtering on dimension r0+rμ and an n-dimensional dynamic matrix update on nrμ states.
Dynamic Low-Rank Lag Matrices (Step 6): 2p separate FFBS passes across state dimensions of size nrB with measurement dimension n.
2. Algorithmic Optimizations for State-Space Recursions (FFBS)
Direct implementation of textbook Kalman updates incurs Om3 complexity per time step, where m is the state dimension. The following structural transformations reduce this burden:
Information Filter Formulation for Network Nodes (Step 3): For each node i, the measurement error covariance is In-1. The update equation in information form avoids inverting n-1×n-1 observation matrices:
Pi,t|t-1=Pi,t|t-1-1+Hi,tu'Hi,tu=Pi,t|t-1-1+j≠ivj,tvj,t'[cite: 1]
Because r≪n, inverting Pi,t|t-1∈Rr×r requires only Or3 operations instead of an On-13 observation inversion.
Low-Rank Measurement Inversion for VAR Blocks (Step 6): The measurement matrix Ht,kU∈Rn×nrB maps into whitened noise εt∼Nn0,In. The innovation covariance St,kU=Ht,kUCt|t-1UHt,kU'+In is an n×n matrix.
Factorize Ht,kU using sparse block indexing: each row i contains non-zero entries only in block column i, turning the computation of Ht,kUCHt,kU' into n decoupled vector outer products rather than a full matrix product.
Solve the Kalman gain Kt,kU=Ct|t-1UHt,kU'St,kU-1 via Cholesky decomposition of St,kU (LSLS'=St,kU) through forward and back-substitution without explicit matrix inversion.
3. Memory Management and Array Layout
Contiguous Memory Buffers:
Store states and observations in column-major format (Fortran-contiguous) to optimize cache hit rates during time-ordered FFBS recursions (t=1…T).
Pre-allocate static working memory for temporary Kalman matrices (mt|t,Ct|t,St,Kt) once prior to the Markov chain loop, overwriting inplace to avoid dynamic heap allocations inside the MCMC iterations.
Pre-computed Adjacency Matrices and Degrees:
Because the binary adjacency series At and normalized weights Wt are determined prior to or updated inside the network layer, cache the sparse row representations of Wt (CSR format) to accelerate the Hadamard matrix product operations Wt-k⊙Bk,t-kxt,k.
4. Parallelization Hierarchy (Multi-Core and GPU Accel)
The Gibbs scheme allows nested shared-memory (OpenMP / Multiprocessing) and SIMD parallelization across multiple granularities:
Node-Level Embarrassing Parallelism:
In Step 1, the truncated normal draws zi,j,t are mutually independent across all dyads i,j and time t. This step distributes across all available CPU threads or compiles to a single GPU vectorized kernel.
In Step 2, the conjugate posteriors for ui (i=1,…,n) and vj (j=1,…,n) depend only on aggregate sums and can be solved concurrently across threads.
In Step 3, the forward filter and backward simulation passes for ui,tt=1T across i=1,…,n are conditionally independent given vj,t and can be mapped across parallel execution threads.
Lag-Level Vectorization:
In Step 8, the hypervariance updates depend on sums of squared Frobenius norms that can be computed via parallel BLAS-1 reduction routines (dnrm2 / ddot).

Step 18: Dynamic System Stability, Local Stationarity Verification, and Shrinkage Priors

1. Verification of Local Stationarity and Dynamic Stability
At every time period t∈1,…,T, the network VAR system has the effective lag-k transition matrix:
Φk,t=In+Wt⊙Bk,t∈Rn×n[cite: 1]
where Bk,t=Uk,tVk,t'.
Companion Matrix Formulation:
Assemble the np×np companion matrix Ft:
Ft=Φ1,tΦ2,t…Φp-1,tΦp,tIn0…000In…00⋮⋮⋱⋮⋮00…In0∈Rnp×np[cite: 1]
Local Spectral Radius Condition:
Compute the spectral radius ρFt=maxi|κiFt|, where κiFti=1np are the eigenvalues of Ft.
Stationarity Criterion: For local stationarity to hold at time t, the spectral radius must remain strictly within the unit circle:
ρFt<1 ∀ t∈1,…,T

5. Post-Processing and Downstream Usage
The resulting variational factor distributions provide analytical representations of the posterior:
