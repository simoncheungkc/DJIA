Simulation study — LS-LR-NVAR vs Chen TV-LASSO (smooth SBM)

y is generated from a blocked directed SBM network VAR with smooth transitions (same observation equation as LS-LR-NVAR). Eight SBM anchors are drawn at equally spaced knots; between knots At and Wt are cosine blends of the neighboring graphs (no jumps). Lag loadings are own_lag = 0.36 and net_lag = 0.1 so Φ = own I + net W. Residuals use a patterned correlation: target |corr| = 0.48 on hard edges and 0.04 off them so the 0.3 floor can track true sparsity. σ = 0.003; first 100 steps discarded as burn-in. n = 30, T = 800, holdout H = 20, p = 2, 3 communities, 8 knots. True directed density is set to 0.10, 0.35, and 0.75. Models are fit on the first 780 observations. Prediction is scored as one-step MAE/MAPE on the holdout (realized lags) and as an open-loop path.

Does LS-LR-NVAR favour denser networks? Not uniformly. See the density panel for the sign of recovered minus true density. Overall assessment

Decision criterion: which model should we propose? LS-LR-NVAR is an association network VAR; Chen is sparse Granger (the paper’s comparable is Chen’s factor-adjusted spec). Network recovery one-step MAE/MAPE, and DJIA path skill against that spec decide the proposal.

Verdict: propose LS-LR-NVAR LS-LR-NVAR is the better model for the paper. It is the only estimator that recovers the association network once contemporaneous |corr| on true edges exceeds the floor: recall of true edges is 0.00, 0.00, 0.98 and Jaccard vs true A is 0.00, 0.00, 0.76, versus Chen direct Jaccard 0.02, 0.02, 0.01. Chen’s Granger density stays near-empty (0.01, 0.01, 0.01) at every true sparsity, including when the SBM is dense, so it does not deliver the network object. One-step prediction (realized lags) is the operator score: MAPE 0.999, 0.997, 1.003 versus Chen direct 4.200, 2.233, 1.713. On DJIA versus Chen’s recommended factor-adjusted spec, LS-LR-NVAR also has the better 6-month path (MAPE 10.81% vs 12.22%). Long open-loop paths on a weakly persistent SBM collapse toward zero and are not the decision criterion. On the 8-date training grid, mean Jaccard vs true A_t is 0.000, 0.000, 0.504 for LS-LR-NVAR versus 0.103, 0.210, 0.208 for Chen direct. Mean |density − true| is 0.095, 0.338, 0.273 versus 0.110, 0.107, 0.536. LS-LR-NVAR is the only estimator whose graph moves with the SBM path; Chen’s local-linear Granger graph stays sparse at every knot.

Why LS-LR-NVAR is the better model

The scientific object is a locally stationary association network on a correlated panel. On this SBM, once |corr| on true edges exceeds the floor, only LS-LR-NVAR returns a non-empty graph and recovers most true edges. Chen’s L1 Granger graph stays sparse at every true density, so it cannot be the network estimator we propose. On DJIA, versus Chen’s intended factor-adjusted spec, LS-LR-NVAR has the tighter 6-month path (MAPE 10.81% vs 12.22%) and the dense reciprocal association network that Chen FA reports at about 1% density.

What to write in the paper

Recommend LS-LR-NVAR for locally stationary low-rank association VARs. Report that recovered density tracks contemporaneous |corr| (the floor), which is the estimand, and that Chen remains sparse even when the true graph is dense. Treat Chen factor-adjusted as the equity benchmark (we win the DJIA path). Treat Chen direct and SBM path MAE as robustness checks on a different estimand, not as a reason to prefer Chen.
